# 분당우리교회 주일학교 수련회 반편성 Tool

엑셀 템플릿으로 명단을 올리고, 참석을 체크한 뒤 날짜별로 반을 짜는 단일 HTML 도구입니다.

1. **명단 올리기**: 템플릿(기본정보·교사·학생 시트)을 내려받아 채운 뒤 올립니다. 교사 역할은 반사/보조교사/스탭/팀장/행정/찬양팀/기타 목록에서 고릅니다.
2. **기본 정보**: 기간, 인원(자동 계산·직접 수정), TF(전체총괄·행정·미디어/예배), 팀 요약.
3. **참석 체크**: 반사·스탭·학생 탭. 엑셀 참석 칸을 읽어 자동 체크하고, 손으로 바꿀 수 있습니다.
4. **팀원 구성**: 팀장·팀원 칸에 선생님을 끌어 놓습니다.
5. **반 배치**: 반은 남학생반·여학생반으로 나뉘고, 학생은 같은 성별 반으로만 옮겨집니다. 날짜 탭마다 반 카드에 선생님과 학생을 끌어 옮깁니다. 불참한 반사는 흐리게 표시됩니다.

**데이터 다운로드**로 받은 파일을 다시 올리면 참석과 날짜별 배치까지 복원됩니다.
데이터는 브라우저(localStorage)에만 저장됩니다. Excel 처리는 ExcelJS(CDN)를 씁니다.
