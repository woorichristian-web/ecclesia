# 수련회 반편성

명단을 붙여넣으면 성별·학년·소속(셀)·교사를 고르게 섞어 반을 나누는 단일 HTML 도구입니다.

- 엑셀에서 복사한 표, CSV/TSV, .xlsx 파일을 읽습니다. 머리글(`이름 성별 학년 소속 역할`)은 자동 인식합니다.
- 반 개수 또는 반당 인원, 혼성반/남녀 분반을 고를 수 있습니다.
- "꼭 같은 반", "서로 다른 반" 규칙을 지원합니다.
- 결과는 끌어서(또는 눌러서) 옮길 수 있고, 옮긴 사람은 고정되어 다시 섞어도 그 반에 남습니다.
- 공지용 글, 엑셀용 표, 반별 표로 복사할 수 있습니다.
- 데이터는 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다.

`index.html`을 브라우저에서 열면 바로 쓸 수 있습니다.
